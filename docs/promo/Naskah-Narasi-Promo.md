# Naskah Narasi Video Promo WA Admin AI

Naskah ini dipakai untuk membuat suara narasi di **ElevenLabs**, lalu digabung dengan video promo:

| Video | Format | Durasi | File video |
|---|---|---|---|
| YouTube | 16:9, 1920×1080 | 71.5 detik | `Promo-YouTube-WA-Admin-AI.mp4` |
| TikTok / Reels / Shorts | 9:16, 1080×1920 | 38.5 detik | `Promo-TikTok-WA-Admin-AI.mp4` |

Video dikirim **tanpa suara**. Gerakan setiap adegan sudah diatur mengikuti naskah di bawah, jadi narasi tinggal ditempel sesuai waktu mulai tiap adegan.

---

## Cara pakai di ElevenLabs

**1. Pilih suara.** Di *Voice Library*, saring bahasa **Indonesian**. Pilih suara yang hangat dan bersemangat, seperti penyiar iklan atau content creator. Untuk TikTok, suara yang lebih santai dan muda biasanya lebih cocok.

**2. Pilih model** yang mendukung bahasa Indonesia, yaitu model *multilingual*. Pilih yang terbaru di akunmu.

**3. Pengaturan awal** (silakan disesuaikan sambil didengar):

| Pengaturan | YouTube | TikTok |
|---|---|---|
| Stability | ±50% | ±40% (lebih ekspresif) |
| Similarity | ±75% | ±75% |
| Style exaggeration | ±20% | ±35% |
| Speed | 1.0 | 1.05–1.1 |

**4. Pakai kolom "Teks untuk ElevenLabs"**, bukan teks biasa. Beberapa kata sudah ditulis sesuai bunyinya supaya dibaca dengan benar:

| Ditulis | Dibaca | Alasan |
|---|---|---|
| WA Admin AI | **We-A Admin Ei-Ai** | Nama produk. Tanpa ini, AI sering terbaca "ai" seperti "air". |
| AI | **Ei-Ai** | |
| WA | **we-a** | |
| scan QR | **sken kiu-ar** | |
| HP | **ha-pe** | |
| dashboard | **dasbor** | |

Kalau suara pilihanmu justru lebih natural membaca "A-I" (a-i), ganti saja **Ei-Ai** menjadi **A-I**. Yang penting konsisten di semua klip.

**5. Buat satu klip per adegan** (cara yang disarankan). Generate tiap kalimat di bawah sebagai file terpisah dan beri nama sesuai kodenya (misalnya `YT-01.mp3`). Setiap klip harus **lebih pendek dari "maks."** di judulnya. Kalau terlalu panjang, naikkan Speed sedikit atau generate ulang. Cara ini membuat suara pas dengan gambar.

## Menggabungkan narasi ke video

### Cara 1: CapCut / editor video (paling mudah)
1. Masukkan file video promo ke timeline.
2. Tempatkan setiap klip narasi (`YT-01.mp3`, `YT-02.mp3`, …) **sekitar 0,3 detik setelah waktu mulai** adegannya (lihat kolom *Waktu* di storyboard).
3. (Opsional) Tambahkan musik latar dan turunkan volumenya ke ±15–20% supaya narasi tetap jelas.
   - YouTube: pakai musik dari **YouTube Audio Library**.
   - TikTok akun bisnis: pakai **Commercial Music Library**. Lagu populer biasa tidak boleh dipakai untuk iklan.
4. Export: YouTube 1080p, TikTok 1080×1920.

### Cara 2: ffmpeg (otomatis, posisi klip langsung pas)
Simpan semua klip di folder yang sama dengan video, lalu jalankan:

**YouTube**
```bash
ffmpeg -i Promo-YouTube-WA-Admin-AI.mp4 -i YT-01.mp3 -i YT-02.mp3 -i YT-03.mp3 -i YT-04.mp3 -i YT-05.mp3 -i YT-06.mp3 -i YT-07.mp3 -i YT-08.mp3 -i YT-09.mp3 -i YT-10.mp3 \
  -filter_complex "[1:a]adelay=300|300[a1];[2:a]adelay=5300|5300[a2];[3:a]adelay=13300|13300[a3];[4:a]adelay=19800|19800[a4];[5:a]adelay=28300|28300[a5];[6:a]adelay=37300|37300[a6];[7:a]adelay=42800|42800[a7];[8:a]adelay=49800|49800[a8];[9:a]adelay=57300|57300[a9];[10:a]adelay=63800|63800[a10];[a1][a2][a3][a4][a5][a6][a7][a8][a9][a10]amix=inputs=10:normalize=0[narasi]" \
  -map 0:v -map "[narasi]" -c:v copy -c:a aac -b:a 192k -shortest Promo-YouTube-dengan-narasi.mp4
```

**TikTok**
```bash
ffmpeg -i Promo-TikTok-WA-Admin-AI.mp4 -i TT-01.mp3 -i TT-02.mp3 -i TT-03.mp3 -i TT-04.mp3 -i TT-05.mp3 -i TT-06.mp3 -i TT-07.mp3 \
  -filter_complex "[1:a]adelay=300|300[a1];[2:a]adelay=3800|3800[a2];[3:a]adelay=8800|8800[a3];[4:a]adelay=15300|15300[a4];[5:a]adelay=21800|21800[a5];[6:a]adelay=25800|25800[a6];[7:a]adelay=30300|30300[a7];[a1][a2][a3][a4][a5][a6][a7]amix=inputs=7:normalize=0[narasi]" \
  -map 0:v -map "[narasi]" -c:v copy -c:a aac -b:a 192k -shortest Promo-TikTok-dengan-narasi.mp4
```

Kalau narasimu satu file utuh yang sudah pas waktunya:
```bash
ffmpeg -i Promo-YouTube-WA-Admin-AI.mp4 -i narasi.mp3 -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest Promo-YouTube-dengan-narasi.mp4
```

### Subtitle
File `Promo-YouTube-WA-Admin-AI.srt` dan `Promo-TikTok-WA-Admin-AI.srt` berisi teks narasi sesuai waktunya:
- YouTube Studio → *Subtitle* → *Upload file* → pilih `.srt`.
- TikTok/CapCut → impor `.srt`, atau pakai fitur *auto caption* setelah narasi ditempel.
